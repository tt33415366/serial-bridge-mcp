# Render SGR colors in the UI, keep transcripts plain

Devices emit ANSI escapes (`ls`, busybox prompts). The Hub now splits the RX stream three ways: `serial_exec` output and the `live/*.log` files get `strip_ansi()` (no escape sequences, no stray control bytes), while the WebSocket transcript gets `sanitize_display()`, which keeps escape sequences and drops other C0 controls so the Web UI can colorize. The browser parses SGR (basic, bright, 256-color, truecolor, bold/dim/underline/inverse) into styled spans against a themed 16-color palette and discards non-SGR sequences such as `ESC[2K`. SGR state resets at each line because the Hub is the one splitting lines. Rejected: stripping escapes for every consumer (loses `ls` colors the Operator relies on) and forwarding raw bytes to the browser untouched (control bytes silently vanish in HTML, which is the bug this replaces).
