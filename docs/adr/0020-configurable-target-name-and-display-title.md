# Configurable Target Name and Display Title (two slots)

MVP keeps exactly two Target Slots. Each Slot has a configurable Agent-facing Target Name (defaults `linux` / `rtos`, `^[a-z][a-z0-9_]{0,31}$`, unique, stored lowercase) and an Operator-facing Display Title (defaults “Linux” / “RTOS”, trim length 1–64, uniqueness not required). Target Name is editable only in CRT Mode; Display Title anytime. Persisted config uses an ordered `slots[]` array; legacy `ports.{linux,rtos}` is migrated and rewritten. Port-binding env vars key off Slot index (`SERIAL_BRIDGE_SLOT0_*` / `SLOT1_*`) with `LINUX_*` / `RTOS_*` as aliases for Slot0/Slot1. Renaming opens `live/<name>.log` anew and leaves the old log file in place. `serial_status` exposes both `name` and `title`. Rejected: Display-Title-only rename, true multi-Target add/remove, and env keys that follow the mutable Target Name.
